## Introduction
Sublime Text is a modern text editor for Windows, Mac and Linux. Some key features include
* Fuzzy sting searching throughout the editor (autocomplete, opening files, searching for symbols)
* Multiple cursors and selections
* Command palette
* Package manager

## Macaulay2 interface
By installing a few packages, one can obtain an interface to Macaulay2 similar to the official Emacs interface.
