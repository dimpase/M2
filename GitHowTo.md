# How to use git with Macaulay2
  * To get the source code of Macaulay2, one "clones" our git repository with the shell command
      `git clone git@github.com:Macaulay2/M2` or with
      `git clone https://github.com/Macaulay2/M2`.  The source code will appear in a directory called `M2`.  Enter it with `cd M2`.
