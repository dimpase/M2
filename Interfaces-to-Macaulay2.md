Macaulay2 is accessible via interfaces from the following software.

* [SageMath](https://sagemath.org) implements [Interface to Macaulay2](https://doc.sagemath.org/html/en/reference/interfaces/sage/interfaces/macaulay2.html)
* [R](https://www.r-project.org) implements [Macaulay2 in R](https://github.com/coneill-math/m2r) which is used by the package [algstat](https://github.com/dkahle/algstat)
